# Mi pequeño experimento aprendiendo Procesamiento de Lenguaje Natural (PLN)

Este repositorio contiene mis primeros pasos y experimentos en el campo del NLP, desarrollados en **Arch Linux** usando **VsCode**.

## 🚀 Contenido
- **Análisis Exploratorio:** Limpieza de texto y tokenización.
- **Librerías utilizadas:** `NLTK`, `spaCy` y `Transformers`.
- **Modelos:** Análisis de sentimientos y extracción de entidades (NER).


## 🛠️ Configuración del entorno
He configurado un entorno virtual de Python para garantizar la reproducibilidad y no corromper mi sistema:
1. He creado el entorno con venv: `python -m venv nlp_env`
2. Por ahora he instalado las dependencias necesarias para empezar este proyecto: `pip install -r requirements.txt`
